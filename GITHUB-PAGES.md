# Как выложить сайт на GitHub Pages

Инструкция для папки `quiz-site`. Займёт 10–15 минут, всё бесплатно. Нужен только аккаунт GitHub (если его нет — зарегистрируйтесь на [github.com](https://github.com)).

## Что получится

Сайт будет открываться по адресу вида:

```
https://ВАШ_ЛОГИН.github.io/quiz-site/
```

Такую ссылку можно отправить участникам или разместить QR-кодом.

---

## Вариант А. Через сайт GitHub, без терминала (проще)

1. На [github.com](https://github.com) нажмите **+ → New repository**.
2. Имя: `quiz-site`. Видимость: **Public** (для бесплатного Pages это обязательно).
3. Не ставьте галочки README/.gitignore — создайте пустой репозиторий кнопкой **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file**.
5. Перетащите **содержимое** папки `quiz-site` (сами файлы: `index.html`, `styles.css`, `app.js`, папки `assets` и `google-apps-script` и т. д.). Не перетаскивайте саму папку `quiz-site` — иначе сайт окажется внутри лишней вложенной папки.
6. Внизу нажмите **Commit changes**.
7. Откройте **Settings → Pages**.
8. В блоке **Build and deployment**:
   - **Source** — **Deploy from a branch**;
   - **Branch** — `main`, папка **/ (root)**;
   - нажмите **Save**.
9. Подождите 1–2 минуты и обновите страницу — сверху появится ссылка `https://ВАШ_ЛОГИН.github.io/quiz-site/`. Откройте её.

## Вариант Б. Через терминал (быстрее, если терминал не пугает)

Выполните в терминале, подставив свой логин GitHub:

```bash
cd "/Users/veronikaselivanova/Documents/deepseek-harness/default-workspace/quiz-site"

git init
git add .
git commit -m "Трактор-квиз КИРОВЕЦ"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/quiz-site.git
git push -u origin main
```

Перед этим создайте пустой публичный репозиторий `quiz-site` на GitHub. При первом `git push` GitHub попросит логин и **Personal Access Token** вместо пароля: **Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token**, галочка `repo`. Токен показывается один раз — сохраните его.

После первого пуша включите Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Если ссылка открывается, но сайт пустой или кривой

| Симптом | Причина и решение |
| --- | --- |
| 404 | Pages ещё не собрались — подождите 2 минуты. Или выбран не тот филиал/папка в настройках. |
| Открывается страница GitHub, а не сайт | Проверьте, что `index.html` лежит в **корне** репозитория, а не в подпапке. |
| Нет фото или логотипа | Папка `assets` не загрузилась или загрузилась с другим написанием. Файлы должны быть: `assets/ptz-logo.png` и `assets/kirovets-k7m-field.jpg`. |
| Изменения не видны | Подождите 1–2 минуты и обновите страницу с ⌘⇧R (жёсткая перезагрузка). |

## Обновления

Чтобы поменять вопросы или оформление, замените нужный файл в репозитории (**Add file → Upload files** или **Edit**) и нажмите **Commit changes**. Через минуту сайт обновится сам.

> Важно: если вы вписали URL Google-скрипта (`sheetsEndpoint`) в `app.js`, то после каждой правки этого файла не забудьте закоммитить новую версию.

---

## Свой домен (необязательно)

Если есть домен, например `quiz.вашсайт.ру`:

1. В настройках репозитория: **Settings → Pages → Custom domain**, введите домен и сохраните.
2. У регистратора домена добавьте CNAME-запись на `ВАШ_ЛОГИН.github.io`.
3. Через несколько часов включите **Enforce HTTPS**.

---

## Что не стоит публиковать

В папке `quiz-site` есть служебные файлы, которые не нужны посетителям:

- `SETUP.md`, `README.md`, `PROMPT.md`, `questions.md` — инструкции и **правильные ответы**;
- папка `google-apps-script` — код для таблицы.

Их можно не загружать на GitHub: сайт работает только за счёт `index.html`, `styles.css`, `app.js` и папки `assets`. Но учтите важное ограничение: сам `app.js` содержит массив вопросов и правильные ответы, поэтому технически подкованный участник сможет их посмотреть. Для школьной викторины это обычно не критично. Если нужно скрыть ответы — скажите, сделаю проверку на стороне Google Apps Script.
